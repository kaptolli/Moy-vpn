# WarpX — 4-режимный VPN (Android)

Одно приложение, четыре режима:

1. **Warp** — подключение к Cloudflare WARP (работает по WireGuard), переключение между профилями.
2. **DPI-обход** (по мотивам byebyedpi) — стратегии обхода DPI (split TLS ClientHello + задержки, fake-преамбула) + автотест, который сам прогоняет стратегии и выбирает лучшую.
3. **Обход белого списка** — для режима изоляции Рунета, когда провайдер режет всё кроме разрешённых сайтов: DNS через DoH (dns.google / cloudflare) + сквозной тунель.
4. **Блокировка** (по мотивам flowseal у Zapret) — резка трафика: drop + RST для заблокированных хостов, kill-switch (блокировать всё кроме allow-списка).

## Что тебе нужно

- Компьютер (Windows/Mac/Linux).
- **Android Studio** — скачай с https://developer.android.com/studio (бесплатно). Ставь стандартно, всё по умолчанию.
- Телефон Android 7.0+ (minSdk 24).

JDK и Android SDK ставить вручную не нужно — Android Studio всё скачает сама при первой синхронизации.

---

## Шаг 1. Открой проект

1. Запусти Android Studio.
2. Первый экран → **Open** (или меню File → Open).
3. Выбери папку **WarpX** (ту, где лежит этот README и файл `settings.gradle.kts`).
4. Появится окно «Trust Project?» → **Trust**.

Пойдёт первая синхронизация Gradle: скачается Gradle 8.6, AGP, зависимости (нужен интернет, первый раз — несколько минут). Жди, пока внизу пропадёт индикатор загрузки.

> Если ругнётся на «Gradle wrapper not found»: жми **Sync** (слоник сверху) → в диалоге выбери **Use Gradle from: 'gradle-wrapper.properties' file** или просто **OK / Fix**. Обычно Android Studio сама всё докачивает.

---

## Шаг 2. Подключи телефон

1. На телефоне: Настройки → О телефоне → жми **«Номер сборки»** 7 раз (включится «Режим разработчика»).
2. Настройки → Система → Для разработчиков → включи **«Отладка по USB»**.
3. Подключи телефон кабелем к компу. На телефоне подтверди «Разрешить отладку по USB».
4. В Android Studio сверху появится название твоего телефона в списке устройств (если нет — File → Sync, или проверь драйвер).

---

## Шаг 3. Собери и установи

Способ A (проще): **запустить прямо на телефоне**
- Жми зелёный треугольник **Run ▶** (или Shift+F10).
- Выбери своё устройство → OK. Приложение соберётся, установится и запустится.

Способ B: **собрать APK-файл**
- Меню **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
- Когда соберётся, внизу появится уведомление «locate» → нажми, откроется папка с `app-debug.apk`.
- Перекинь этот APK на телефон (кабель/Telegram/почта) и установи (разреши установку из неизвестных источников).

## Шаг 4. Пользование

В приложении 4 радиокнопки + кнопки:

- **1 · Warp** — нужен профиль WireGuard. Сначала импортируй его: кнопка **«Импорт Warp-профиля»** → выбери `.conf`-файл. Потом «Подключить».
  Как получить Warp-профиль: конфиг WireGuard из WARP генерируют утилиты **wgcf** (github.com/ViRb3/wgcf) или **warp-cli** — на выходе `.conf` с `[Interface]`/`[Peer]`, который мы и импортируем.
- **2 · DPI-обход** — выбери и жми «Подключить». Стратегию можно выбрать автоматически: **«Автотест стратегий»** (лучше запускать **до** подключения, VPN выключен).
- **3 · Обход белого списка** — просто «Подключить». DNS идёт через DoH, весь трафик через тунель.
- **4 · Блокировка** — «Подключить». Списки блокировки настраиваются в коде (`Mode.denyHosts` / `allowHosts` / `blockAll` в `modes/Mode.kt`) — в v1 без GUI-редактора.

Кнопка **«Отключить»** останавливает текущий режим.

При первом «Подключить» Android спросит разрешение VPN — **соглашайся**.

## Важные честные ограничения (v1)

- **IPv4-only.** IPv6-трафик в v1 не туннелируется (идёт напрямую). Для большинства задач достаточно; фикс — в следующей итерации.
- **TCP** обрабатывается полностью; **UDP** — DNS (через DoH) и обычный NAT-релей.
- **DPI-обход** работает на уровне TCP-прокси (фрагментация ClientHello с задержкой, fake-преамбула). «Сырые» трюки byebyedpi по TTL/MSS/seq требуют root — на Android без root их нет, поэтому стратегии — прокси-уровня.
- **flowseal** у нас — не root-эквивалент (drop + RST + kill-switch), а не перехват пакетов как у оригинального zapret.
- Стратегии DPI со временем устаревают (провайдеры адаптируются) — автотест помогает переподобрать рабочую.

## Если что-то не собирается / не работает

- **Синхронизация виснет** — проверь интернет, File → Sync Project with Gradle Files.
- **Gradle version** — в File → Settings → Build Tools → Gradle выбери **Use Gradle from: wrapper**, distribution — 8.6.
- **Ошибка libwg-go** при подключении Warp — библиотека WireGuard не смогла загрузить нативный код (редкий случай на экзотических прошивках); попробуй другой девайс/прошивку.
- **VPN подключается, но сайты не открываются** — в режиме 2 запусти «Автотест» и переподключись; в режиме 4 проверь, что `blockAll` выключен, если не настраивал списки.
- **Нет уведомления** на Android 13+ — выдай приложению разрешение «Уведомления» (не критично).
